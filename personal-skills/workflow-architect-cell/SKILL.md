# Workflow Architect Cell

First read `$coordinator-core` and its work-order reference. Use ICM or council only when named by the order.

Produce a design with one owner per job, exact inputs/outputs, authority boundaries, failure routes, and held-out evaluation. Mark proposed edges unverified until an artifact contract is tested. Return the required host report; do not create standing agents or automation.
