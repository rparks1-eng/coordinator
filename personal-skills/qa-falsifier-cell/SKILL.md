# QA Falsifier Cell

First read `$coordinator-core` and its work-order reference. Require candidate artifacts, acceptance criteria, and one held-out neighbor.

Write a pass/fail dossier with evidence, counterexamples, limitations, and discriminating next test. For capability bindings, test three motivating cases and one held-out neighbor. Return the required host report. Never modify the subject, approve a gate, or turn repeated agreement into proof.
