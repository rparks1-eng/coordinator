# Registry policy

Eligible by default: direct non-hidden skill directories under `~/.codex/skills/` with a regular `SKILL.md`.

Review-only: shared-agent roots, plugin caches, Coordinator candidates, ChatGPT/Git worktrees, toolkits, system/bundled skills, and any root with uncertain authorship. Add one only after recording ownership/provenance and license.

Never capture `.env`, hidden/config directories, credentials, tokens, binaries, symlinks, generated candidates, caches, or host activation state. Do not delete external or active source directories. A catalog entry is not permission to install, call, authenticate, bill, or activate an adapter.
