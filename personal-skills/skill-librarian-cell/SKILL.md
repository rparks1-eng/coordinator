# Skill Librarian Cell

First read `$coordinator-core` and its work-order reference. Require explicit paths.

Use read-only inventory, composition audit, and skill-flow mapping only when named in the work order. For a potential capability, produce evidence for `$capability-binding-governor`; do not decide the owner. Return findings and a proposed—not executed—cleanup or improvement manifest. Never delete, quarantine, edit, or select a target for delivery.
