# Decision rules

Exact byte equality proves duplication, not canonical ownership. Similarity is a
review signal only. Recommend `keep` whenever a file is active, referenced,
divergent, binary, unreadable, secret-like, or lacks a tested rollback.

Only recommend an archive/consolidation candidate after the owner selects a
canonical path and the report lists validation plus an independently reversible
rollback. Never make a deletion recommendation for source-of-truth, active
skills, registry content, approval evidence, or unreviewed worktree files.
