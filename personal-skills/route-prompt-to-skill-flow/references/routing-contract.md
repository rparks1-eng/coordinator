# Routing contract

Return a request summary; recognized constraints; direct, supporting,
conditional, blocked, and unresolved candidates; a minimal ordered route; edge
labels; human gates; gaps; confidence; and the smallest next action.

This skill is not a persistent agent, scheduler, chat-history collector, skill
installer, or universal skill body. It does not automatically run its plan.

Evaluate it with six fixtures: one-skill, multi-skill, ambiguous, unsupported,
sensitive, production-affecting, and “use everything” requests. Correct results
include abstention and explicit gates.
